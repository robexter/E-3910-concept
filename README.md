## Publicação no GitHub Pages
1. Extraia o ZIP.
2. Envie **todos os arquivos e a pasta `icons`** para a raiz do repositório.
3. Em **Settings > Pages**, publique pela branch `main` e pasta `/(root)`.
4. Abra a URL HTTPS no celular.
5. Use o botão **📲 Instalar E-3910 concept**.

### Caso o navegador mantenha versão antiga
- altere o `CACHE_NAME` do `sw.js` de `e3910-concept-v1` para `e3910-concept-v2`;
- publique novamente;
- depois feche e reabra o navegador/app.
